# koreapilates.or.kr 실도메인 전환 체크리스트

Wix → GitHub Pages(Astro) 로 도메인을 옮기는 절차입니다.
**메일(하이웍스)은 반드시 그대로 살려야 합니다** — 아래 MX/TXT 를 빠뜨리면 메일이 끊깁니다.

## 전환 전 원본 DNS (Wix 네임서버에서 추출, 2026-09-01)

| 종류 | 호스트 | 값 |
|---|---|---|
| NS | @ | ns2.wixdns.net / ns3.wixdns.net |
| A | @ | 185.230.63.107 / .171 / .186 (Wix) |
| CNAME | www | cdn3.wixdns.net. (Wix) |
| **MX** | **@** | **10 mailapp.hiworks.co.kr.** ← 하이웍스 메일 |
| **TXT** | **@** | **v=spf1 include:_spf.hiworks.co.kr ~all** ← 하이웍스 SPF |

그 외 서브도메인·DMARC·DKIM 레코드는 없었습니다.

## 1. 코드 (✅ 완료)

- `astro.config.mjs`: `site` → `https://koreapilates.or.kr`, `base` → `/`
- `public/CNAME` 추가
- 파비콘 로컬 호스팅 → 빌드 산출물에 Wix 의존성 0

> 가비아 주의사항 (sportsclubphillip 전환 때 겪은 것들)
> - CNAME·MX 값은 **끝에 점(.)** 을 붙일 것
> - MX 는 **우선순위(10)** 칸을 반드시 채울 것
> - SPF 는 **띄어쓰기 그대로** 넣을 것

## 4. GitHub Pages 커스텀 도메인 지정

DNS 가 GitHub IP 로 응답하기 시작한 뒤 실행:

```bash
gh api --method PUT repos/SoojinJung7/koreapilates.or.kr/pages \
  -f cname=koreapilates.or.kr -F https_enforced=true
```

인증서 발급까지 보통 수 분. `http://www`(https 아님)는 www 인증서가 끝날 때까지
잠깐 404 가 날 수 있고 1시간 내 자연 해소됩니다.

## 5. 검증

```bash
dig +short koreapilates.or.kr          # → 185.199.10x.153
dig +short MX koreapilates.or.kr       # → 10 mailapp.hiworks.co.kr.  (메일 살아있나)
curl -sI https://koreapilates.or.kr    # → 200
curl -sI https://www.koreapilates.or.kr # → 301 → apex
```

메일 실수신 테스트(외부에서 한 통 보내보기)까지 확인한 뒤 **Wix 해지**.
